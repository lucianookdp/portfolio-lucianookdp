# lucianookdp.github.io

Personal portfolio site — Astro + TypeScript, Tailwind CSS, a WebGL shader
hero, PT/EN content, and a `⌘K` command palette. Fully static, deployed to
GitHub Pages via GitHub Actions.

## Stack

Astro · TypeScript · Tailwind CSS · React (islands) · Motion · OGL

## Running locally

```bash
npm install
npm run dev
```

```bash
npm run build   # build the static site
npm run preview # preview the production build
npm run check   # type-check
```
